# TitãsBot Frontend

Interface web do TitãsBot (Vite + React).

## Pré-requisitos

- Node.js 18+
- npm

## Rodar localmente

No diretório `front`:

1. Instalar dependências:
   ```bash
   npm install
   ```
2. Iniciar ambiente de desenvolvimento:
   ```bash
   npm run dev
   ```

## Build de produção

```bash
npm run build
```

## Observação

Este frontend consome o backend do projeto (endpoint `/chat`).
Certifique-se de iniciar o servidor do backend antes de testar o chat.
